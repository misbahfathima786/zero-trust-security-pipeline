# 🔐 Software Supply Chain Security – Zero-Trust Security Enforcement Pipeline

## 📌 About the Project

This project aims to improve software supply chain security by automatically checking application code and dependencies for potential security issues.

The pipeline will use security scanning tools and automated workflows to identify risks and enforce defined security policies.

## ⚠️ Problem Statement

Software projects may contain exposed secrets, vulnerable dependencies, and insecure container images. Identifying these issues early helps reduce security risks during software development.

## 🎯 Objectives

- ⚙️ Automate security checks through GitHub Actions.
- 🔑 Detect exposed secrets using Gitleaks.
- 🛡️ Scan dependencies and container images using Trivy.
- 🚦 Enforce configurable security pass/fail rules.
- 📊 Build a Flask-based security dashboard.
- 📦 Generate a Software Bill of Materials (SBOM).
- 📈 Maintain scan history and analyze security trends.

## 🧰 Technology Stack

- 🐍 Python and Flask
- 🐙 Git and GitHub
- 🐳 Docker
- 🔄 GitHub Actions
- 🔍 Gitleaks
- 🛡️ Trivy
